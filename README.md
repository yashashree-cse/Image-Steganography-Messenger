Image Steganography Messenger

Project Overview
Image Steganography Messenger is a web-based project designed to hide secret messages inside images and retrieve them when needed.

Features
- Hide messages inside images
- Retrieve hidden messages
- Password-based protection
- Custom background
- Real-time chat-style interface

Technologies Used
- HTML
- CSS
- Java

Purpose
The project demonstrates the concept of image steganography, which involves concealing information within an image.

Project Type
Mini Project — Computer Science and Engineering
